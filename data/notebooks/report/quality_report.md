# Отчёт о качестве данных: Музеи мира

## 1. Введение

**Датасет:** `world_museums_complete.csv` — данные о музейной инфраструктуре разных стран мира за разные годы. Содержит общее количество музеев, разбивку по типам (искусство, история, наука), экономические показатели (ВВП на душу, доход от туризма, бюджет на культуру) и число объектов UNESCO.

**Предполагаемый заказчик:** Международный совет музеев (ICOM) или аналитический отдел Министерства культуры. Цель — понять факторы, влияющие на развитие музейной сети, и выявить аномалии в данных.

**Задачи интеллектуального анализа данных (ИАД):**
1. **Поиск аномалий (выбросов)** — найти страны/годы с нереалистичным количеством музеев (ошибки учёта, дубликаты).
2. **Описательная аналитика** — определить связь между культурным бюджетом, ВВП и числом музеев.

## 3. Основные проблемы качества данных

| № | Тип проблемы | Описание (где и что) | Потенциальный риск для анализа | Предлагаемое решение / стратегия |
|---|---|---|---|---|
| 1 | Пропуски | Отсутствуют во всех столбцах | Риска нет, данные предварительно очищены | Оставить как есть |
| 2 | Дубликаты | Обнаружены дублирующиеся пары (country, year) — одна страна и год встречаются несколько раз с разными значениями total_museums | Искажение статистики (средних, сумм) при агрегации | Усреднить значения по дубликатам или оставить только последнюю запись |
| 3 | Выбросы | total_museums > 30 000 (Перу 2023, Куба 2021, Ямайка 2022, Колумбия 2018 и др.) | Может быть ошибкой учёта (учтены не музеи, а объекты наследия) | Проверить по внешним источникам; при моделировании использовать робастные методы или логарифмирование |
| 4 | Подозрительные нули | total_museums == 0 для нескольких строк (Senegal, Nigeria, Ethiopia и др.) | Неправдоподобное значение — вероятно, пропуск заменён на 0 | Заменить на NaN, затем заполнить медианой по региону |
| 5 | Непропорциональная выборка по регионам | Europe — много записей (>200), Africa и Oceania — мало (<50) | Сравнение между регионами будет смещённым | Применять взвешивание или стратификацию при анализе |
| 6 | Разброс данных по годам | Данные собраны за разные годы (2015–2023), не для всех стран есть все годы | Нельзя напрямую сравнивать страны без учёта года | При анализе учитывать year как признак или фильтровать по одному году |

## 4. План улучшения качества данных

### Приоритет 1 (критично — сделать сразу)
1. **Обработать дубликаты по (country, year)** — объединить строки (взять среднее или последнее значение).
2. **Проверить выбросы через внешние источники** — убедиться, что такие страны действительно имеют десятки тысяч музеев.
3. **Заменить нули в total_museums на NaN**, затем заполнить медианой по региону.

### Приоритет 2 (важно для анализа)
4. **Создать новые признаки**:
   - `museums_per_million` — музеев на миллион населения
   - `art_percent` — доля художественных музеев
   - `science_percent` — доля научных музеев
5. **Нормализовать числовые признаки** (MinMaxScaler или StandardScaler) для дальнейшего моделирования.

### Приоритет 3 (можно отложить)
6. **Выровнять частоты регионов** — применить undersampling для Europe или oversampling для Africa/Oceania.
7. **Привести все строковые признаки к нижнему регистру** и удалить лишние пробелы (для страховки).
